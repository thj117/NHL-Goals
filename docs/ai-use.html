  1. Make Necessary Adjustments for Nominal Response Target Bin goals into nominal categories: ‘Low’ (0-1), ‘Medium’ (2-3), ‘High’ (4+)
df <- df %>%
mutate(
goals_nominal = case_when(
goals <= 1 ~ "Low_Goals",
goals <= 3 ~ "Medium_Goals",
TRUE ~ "High_Goals"
),
goals_nominal = as.factor(goals_nominal)
)
  1. Feature Selection & Data Cleaning Drop target leakage (‘won’, ‘powerPlayGoals’), raw ‘goals’, and IDs
leakage_cols <- c("goals", "won", "powerPlayGoals", "game_id", "team_id", "head_coach")
df_model <- df %>%
select(-any_of(leakage_cols)) %>%
mutate(across(where(is.character), as.factor)) %>%
drop_na()
  1. Train/Test Split (Stratified by goals_nominal)
train_index <- createDataPartition(df_model$goals_nominal, p = 0.8, list = FALSE)
train_data <- df_model[train_index, ]
test_data <- df_model[-train_index, ]

set.seed(42)

train_data$goals_nominal <- relevel(train_data$goals_nominal, ref = "Low_Goals")
test_data$goals_nominal <- relevel(test_data$goals_nominal, ref = "Low_Goals")

AI Check 1

During AI given model correctly looks at the goals as ordinal values. By turning them into catagorical values. I would be cautious looking at the data, because of the way the values are just being dropped. By just dropping the data it might affect the model and the predictions there needs to be a different way to clean the data.

AI Check 2

The goals are already somewhat ordinal, so maybe they just need to be ordered and catagorized. Then the predictors aren’t scaled accurately all of the variables have different ranges and values and need to be standardized.
